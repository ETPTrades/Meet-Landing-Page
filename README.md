**Project Overview:**

With this project the goal was responsiveness. I was given a mobile, tablet, and desktop design, and I had to follow the design files to the best of my ability. It also gave me the opportunity to flex my CSS Grid and Flex-Box muscles. Really great "seasoned beginner" project for practicing responsiveness, and even though it wasn't perfect, I'll definitely be going back to improve upon it.

**Built With:**

- CSS Grid
- Flex-Box

**Learning Reflection:**

Lots learned here. I got hands on experience with:

- semantic HTML
- CSS Grid
- Flex-Box
- CSS Logical Properties
- Clamp Function

and lots more. Definitely ran into issues at every turn, but in figuring out those issues it makes you a better programmer and better suited to handle the next one. This is actually the first project in the Responsive Design learning path that is going to go unfinished for the time being, and the first project that I'm probably going to need to get help with when it comes to little tweaks here and there. The learning process is tough, but necessary. Looking forward to the next challenge.
